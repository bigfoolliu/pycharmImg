# 图片链接预览插件总体技术方案

首版功能边界与验收要求以[技术规范与总体架构](图片链接预览插件技术规范与总体架构.md)为准；本文记录后续实现阶段可参考的技术选型。

## 1. 目标与范围

插件面向 **Apple Silicon、macOS 15.6、PyCharm 2024.1.7 Professional（构建号 `PY-241.19416.19`）**。用户在已打开文件的 `http://` 或 `https://` 链接上短暂停留时，若该地址返回可解码的图片，就在编辑器附近显示缩放后的预览；鼠标移开或切换文件时关闭。普通网页、失效链接和非图片响应不显示图片。[JetBrains 旧版本下载页](https://www.jetbrains.com/pycharm/download/other/)

首版只处理文本编辑器中的网络链接。暂不支持本地或相对路径、需登录的图片、编辑器内嵌图片、项目级扫描、下载管理或设置页面。图片格式以 JVM 内置解码器可处理的 PNG、JPEG、GIF 为首版范围；GIF 显示静态首帧。SVG、WebP 等格式留待后续按实际需要评估。

## 2. 技术选型

- **语言与构建**：Java 17、Gradle Wrapper 9.8.1、IntelliJ Platform Gradle Plugin 2.x；目标 IDE 为 PyCharm Professional `2024.1.7`，默认下载 SDK，也可通过 `PYCHARM_HOME` 使用本机安装。首版只声明并验证 `PY-241.19416.19` 的兼容性；若以后扩大到其他构建号，再调整 `since-build`/`until-build` 并逐一验证。选用 Java 可避免目标 IDE 自带 Kotlin 库与新版 Kotlin 构建插件的版本冲突。[官方版本表](https://plugins.jetbrains.com/docs/intellij/build-number-ranges.html) · [Gradle 插件](https://plugins.jetbrains.com/docs/intellij/tools-intellij-platform-gradle-plugin.html)
- **平台接口**：通过 `com.intellij.editorFactoryMouseMotionListener` 接收编辑器鼠标移动事件；使用编辑器的坐标与文档偏移定位链接；用 `JBPopupFactory` 显示包含图片的轻量弹窗。这些均属于 IntelliJ Platform 能力，首版无需 Python PSI、外部 Python 进程或本地动态库。[扩展点列表](https://plugins.jetbrains.com/docs/intellij/extension-point-list.html) · [编辑器坐标](https://plugins.jetbrains.com/docs/intellij/coordinates-system.html) · [弹窗](https://plugins.jetbrains.com/docs/intellij/popups.html)
- **网络与解码**：使用 JDK 的 `HttpURLConnection` 和 `ImageIO`，不引入额外网络或图像依赖。网络与解码在后台执行，仅在 EDT 更新弹窗。[线程模型](https://plugins.jetbrains.com/docs/intellij/threading-model.html)

## 3. 核心流程

1. 鼠标在文本编辑器移动时，取消前一次尚未开始的任务；停留约 **400 毫秒**后，将位置换算为文档偏移，只检查该偏移所在的**一行**。
2. 在该行提取覆盖鼠标位置的完整 HTTP(S) URL，剔除外围引号、包裹 URL 的右括号和句末标点，保留 URL 内成对的括号。无法判定是否属于外围标点的孤立右括号予以保留。识别只在内存中进行，不请求网络，也不修改文件。跨行拼接或变量生成的 URL 不在首版范围。
3. 对有效 URL 发起一次后台请求。每个项目只执行一个图片请求，并仅保留最新的待处理请求；取消或超时会断开当前连接。仅接受成功响应及可解码的 PNG、JPEG、GIF；部分 CDN 的响应类型或声明长度不准确，因此以实际读取字节数和图片内容决定是否预览。限制重定向次数、实际下载字节数与解码前的像素尺寸。首版超时约 **5 秒**、最大 **5 MiB**、最大 **4096 × 4096** 像素。
4. 大图在解码阶段先按采样率缩小，再将图片按比例缩放到约 **480 × 320** 像素内，避免为预览分配完整尺寸的图像缓冲区。若鼠标位置、当前文件或文档内容已变化，丢弃过期结果。
5. 对已成功解码的图片保留小型内存缓存，例如最多 **16 张**；关闭项目或卸载插件时释放。失败结果不长期缓存，避免网络恢复后仍无法预览。

若 URL 没有图片后缀，也照常尝试请求；图片身份以实际解码结果判断。请求不携带 PyCharm 登录信息，也不记录图片内容或含凭据的完整 URL。弹窗关闭、编辑器销毁或项目关闭时取消关联任务。网络异常只给出简短提示或静默关闭，不影响编辑器输入。

## 4. 模块划分

| 模块 | 职责 |
| --- | --- |
| 编辑器监听 | 监听悬停，控制延时、取消与弹窗生命周期 |
| 链接识别 | 从鼠标所在行提取 URL，返回文本范围和规范化地址 |
| 图片加载 | 限时下载、校验响应、限制大小、解码与缩放 |
| 预览弹窗 | 显示图片或简短失败状态，不持有项目文件内容 |

初期保持单模块 Gradle 工程，不增加数据库、后台服务或复杂配置层。

## 5. 验证与交付

- **单元测试**：URL 提取覆盖 Python 字符串、Markdown、普通文本、多个链接、括号与标点；图片校验覆盖无后缀图片、非图片、损坏数据、超限与重定向。
- **集成验证**：在 macOS 15.6 的 Apple Silicon 机器上运行 PyCharm Professional 2024.1.7 沙盒，检查悬停预览、快速移动鼠标、编辑链接、切换标签页和关闭项目时的行为；确认网络请求没有阻塞输入。
- **构建检查**：运行 `./gradlew test`、`./gradlew runIde`、`./gradlew buildPlugin`，并用 Plugin Verifier 检查所声明的 PyCharm 构建号。[Gradle 任务](https://plugins.jetbrains.com/docs/intellij/tools-intellij-platform-gradle-plugin-tasks.html) · [兼容性验证](https://plugins.jetbrains.com/docs/intellij/verifying-plugin-compatibility.html)

## 6. 首版交互决策

目标 IDE 版本已确定为 **2024.1.7 / `PY-241.19416.19`**。本方案暂定“悬停约 400 毫秒后预览”，作为无需额外按钮的轻量交互；若实际使用中弹窗干扰编辑，可改为点击链接旁的预览入口。
